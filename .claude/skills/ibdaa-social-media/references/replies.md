# ردود الكومنتات والرسايل

Adapt tone to the comment; keep replies 1–2 lines; use the person's name when visible.

| الموقف | الرد |
|---|---|
| «بكام؟» في الكومنت | «أهلًا يا [الاسم] 🙌 بعتنالك التفاصيل والأسعار في رسالة» (then actually send the DM) |
| مدح | «تسلم يا [الاسم]! ده من ذوقك 🧡» |
| سؤال عن مدة التنفيذ | «حسب نوع الشغل، الريلز البسيط بيبقى جاهز في أيام. ابعتلنا فكرتك ونقولك بالظبط» |
| «ده معمول بالـ AI؟» | Be honest: «فيه أجزاء بنستخدم فيها أدوات AI، والفكرة والإخراج والمونتاج شغلنا إحنا» |
| نقد محترم | «شكرًا على رأيك، ده يفيدنا جدًا وهناخده في الاعتبار» |
| شكوى عميل | «حقك علينا يا [الاسم]، كلمناك في رسالة عشان نحلها حالًا» → solve in DM |
| سبام / إساءة | Don't reply; hide or delete. |

## First DM to a lead
```
أهلًا يا [الاسم]، معاك فريق إبداع بيتحرك 👋
عشان نديك سعر دقيق، محتاجين نعرف:
1) نوع الشغل (موشن / تصميم / مونتاج / ريلز)
2) المدة أو عدد التصميمات
3) هتنشره فين
4) محتاجه إمتى
وابعتلنا أي مثال عاجبك لو موجود.
```
