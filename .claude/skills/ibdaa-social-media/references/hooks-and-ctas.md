# Hooks & CTAs بالعامية المصرية

Pick the formula that fits the goal, then rewrite it for the specific client — never paste an example as-is.

## Hook formulas
| # | الفورمولا | مثال |
|---|---|---|
| 1 | سؤال بيوجع | «إعلانك بيتشاف ومحدش بيكلمك؟» |
| 2 | رقم محدد | «3 ثواني بس… دي كل اللي معاك قبل ما يقلب» |
| 3 | غلطة شائعة | «أكبر غلطة في فيديوهات المطاعم: بتبدأ باللوجو» |
| 4 | قبل / بعد | «ده كان البوست قبل… وده بعد ما اتحرك» |
| 5 | سر المهنة | «الفرق بين إعلان رخيص وإعلان غالي مش في الكاميرا» |
| 6 | النتيجة الأول | «عملنا فيديو 15 ثانية… جاب للعميل رسايل أكتر من الشهر كله» (real results only) |
| 7 | تحدي / مقارنة | «نفس المنتج، فيديوهين… انهي هيبيع؟» |
| 8 | قصة قصيرة | «العميل جالنا ومعاه صورة واحدة بس…» |
| 9 | موجّه لجمهور محدد | «لو عندك براند هدوم أونلاين، البوست ده ليك» |
| 10 | ترند / موسم | «رمضان داخل… إعلانك جاهز؟» |
| 11 | ورا الكواليس | «تعالى نوريك الفيديو ده اتعمل إزاي من الصفر» |
| 12 | رأي جريء | «البوست الثابت لوحده مبقاش كفاية» |

## CTAs
| الهدف | CTA |
|---|---|
| رسايل / عملاء | «ابعتلنا رسالة وهنرد عليك بالتفاصيل» · «كلمنا واتساب» · «اكتب "عايز" في الكومنتات» |
| تفاعل | «قولنا رأيك: الأولى ولا التانية؟» · «منشن حد محتاج يشوف ده» |
| حفظ / مشاركة | «احفظ البوست ترجعله وإنت بتعمل إعلانك الجاي» |
| متابعة | «تابعنا… كل أسبوع شغل جديد بيتحرك» |
| عرض محدود | «العرض لحد يوم الخميس بس» (only if it's real) |

## Arabic writing checks
- Line 1 ≤ ~60 characters so it isn't cut before «عرض المزيد».
- Numbers as digits in captions (3، 15، 30%) — readable on mobile.
- Avoid fusha stiffness: «إحنا» not «نحن», «عايز» not «تريد», but keep spelling clean.
- Read it aloud: if it sounds like an ad translated from English, rewrite.
